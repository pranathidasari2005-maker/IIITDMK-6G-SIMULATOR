SIMULATION FRAMEWORK

From Network Models to 6G Experiments

IIITDMK 6G SIMULATOR provides a reusable environment for modelling and experimenting with next-generation network scenarios. The framework combines network entities, resource states, capability management, services and sessions with an ns-3 based simulation backend.

The framework is designed to study how network resources and capabilities can change dynamically during simulation and how higher-level services interact with these network conditions.
